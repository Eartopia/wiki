# 🖥️ 홈페이지 이용하기

[Eartopia 홈페이지](https://www.eartopia.net/)에서는 서버 소개, 낚시 도감, 내 정보와 앨범을 볼 수 있어요.

## 로그인하기

1. 마인크래프트에서 Eartopia에 접속해요.
2. 홈페이지의 **로그인**을 눌러요.
3. 접속 중인 **마인크래프트 닉네임**을 입력하고 인증코드를 요청해요.
4. 게임 안으로 도착한 코드를 홈페이지에 입력해요.
5. 인증을 마치면 내 계정으로 연결돼요.

코드의 유효시간이 지났다면 새로 요청해 주세요. 홈페이지에 마인크래프트 비밀번호를 입력하는 방식이 아니에요.

{% hint style="warning" %}
인증코드는 다른 사람에게 알려주지 마세요. 공동으로 사용하는 컴퓨터에서는 이용을 마친 뒤 로그아웃해 주세요.
{% endhint %}

## 로그인한 뒤 할 수 있는 일

| 페이지 | 하는 일 |
| --- | --- |
| [마이페이지](https://www.eartopia.net/me) | 내 계정의 진행도와 정보를 확인해요. |
| [스킨](https://www.eartopia.net/wiki/skins) | 아이템 스킨과 캐릭터 꾸미기를 따로 살펴봐요. |
| [앨범](https://www.eartopia.net/album) | 내가 찍은 사진을 보고 내려받아요. |
| [연주](https://www.eartopia.net/instruments) | 게임 속 악기와 웹 건반·MIDI를 연결해요. |

낚시 정보를 먼저 보고 싶다면 [웹 낚시 도감](https://www.eartopia.net/wiki/fishing)을 열어보세요.

## 코드가 오지 않아요

게임에 접속 중인지, 입력한 닉네임이 맞는지 확인해 주세요. 요청을 반복하기 전에 안내된 대기 시간을 기다려요. 계속 실패하면 홈페이지의 오류 문구를 알려주세요.
