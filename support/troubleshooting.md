# 🛠️ 문제 해결

## 접속이 거절돼요

버전 안내가 나오면 **실행 버전과 최신 접속 공지**를 확인해요. 허용 목록 안내가 나오면 디스코드의 참여 절차를 확인해 주세요. [접속 방법](../start/join.md)에 순서가 있어요.

## 글자나 전용 아이템이 깨져요

서버 리소스 팩을 **사용**으로 바꾸고 다시 접속해요. 다운로드가 끝난 뒤에도 같다면 개인 UI·글꼴 팩을 잠시 끄고 확인해 주세요.

팩 업데이트 안내가 나왔을 때는 `/resourcepacks update`를 사용해요. 자세한 내용은 [리소스팩](../start/resource-packs.md)을 참고해 주세요.

## 패널의 버튼과 클릭 위치가 달라요

`/panels calibrate`로 [커서 보정](panel-cursor-calibration.md)을 진행해요. 게임의 조준점을 빨간 점에 맞춰 클릭해 주세요.

보정 후 더 불편해졌다면 `/panels calibrate reset`으로 기본값으로 돌아갈 수 있어요.

## 화면의 안내가 깜빡여요

메인 메뉴의 **설정 → 저사양 모드**가 켜져 있다면 끈 뒤 비교해 보세요. [편의 설정](../start/settings.md)에 설명이 있어요.

## 튜토리얼이 넘어가지 않아요

리소스팩 다운로드가 끝났는지 확인해요. 우클릭이나 웅크리기로 다음 안내를 넘길 수 있지만, 장면을 조금 더 보라는 안내가 나오면 잠시 기다려야 해요.

계속 멈춰 있다면 보이는 장면과 안내 문구를 남겨 문의해 주세요. 일반 플레이어가 튜토리얼 관리 명령어를 입력할 필요는 없어요.

## 아이템을 받지 못했어요

| 상황 | 먼저 확인할 것 |
| --- | --- |
| 요리가 완성됐어요 | 인벤토리를 비우고 조리대를 우클릭해요. 보관 안내를 받았다면 `/cooking claim`을 확인해요. |
| 교역 가공·교환을 마쳤어요 | `/trade deliveries`를 확인해요. |
| 탐사 보상을 얻었어요 | `/wildlife`의 **보상 받기**를 확인해요. |
| 녹음을 끝냈어요 | `/einstruments recordings`에서 저장된 녹음을 확인해요. 음반은 따로 추출해요. |

거래나 수령 결과를 확인할 수 없다는 메시지가 나온다면 같은 동작을 반복하지 말고 문의해 주세요.

## 그래도 해결되지 않아요

[공식 디스코드](https://discord.gg/tymyqkCJW7)에 **발생 시각·조작 순서·안내 문구·스크린샷**을 함께 남겨주세요. 로그인 인증코드는 가려주세요.
