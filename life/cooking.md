# 🍳 요리

Eartopia의 요리는 **전용 오븐과 가스레인지**에서 만들어요. 레시피를 고르고, 화력을 조절하고, 완성된 음식을 직접 받아가면 돼요.

## 요리 시작하기

1. 사용할 수 있는 전용 조리대를 찾아 우클릭해요.
2. 레시피 수첩에서 배운 요리를 골라요.
3. 필요한 재료와 부족한 수량을 확인해요.
4. 재료를 인벤토리에 준비한 뒤 **조리 시작**을 눌러요.
5. 조리 중 **화력 조절** 안내가 뜨면 조리대를 우클릭해요.
6. 완성 안내가 나오면 다시 우클릭해서 음식을 받아요.

{% hint style="warning" %}
화력 조절을 놓치면 음식이 타요. 조리를 시작한 뒤에는 조리대 가까이에서 안내를 확인해 주세요.
{% endhint %}

## 레시피가 보이지 않아요

레시피 수첩에는 **내가 배웠고, 지금 조리대에서 만들 수 있는 요리**가 나와요. 오븐용 요리는 가스레인지에서 찾을 수 없어요.

[탐사 수첩](wildlife.md)의 이야기를 진행하면 들녘 채소 수프의 레시피와 첫 요리를 위한 도움을 받을 수 있어요. 다른 요리도 레시피의 습득 조건과 필요한 수준을 확인해 주세요.

## 처음 만들어볼 요리

**들녘 채소 수프**는 가스레인지에서 만들어요. 배운 뒤 아래 재료를 준비해 주세요.

| 재료 | 수량 |
| --- | ---: |
| 감자 | 2개 |
| 당근 | 1개 |
| 밀 | 1개 |
| 그릇 | 1개 |

기본 조리 시간은 **18초**, 화력 조절은 **1회**예요. 완성해서 먹으면 탐사 이야기의 다음 단계에도 도움이 돼요.

## 완성된 음식 받기

음식은 **조리를 시작한 사람**이 받아요. 인벤토리가 가득 찼다면 공간을 비운 뒤 조리대를 다시 우클릭해 주세요.

보관된 결과가 있다는 안내를 받았다면 `/cooking claim`으로 받을 수 있어요. 완성한 요리의 기록은 `/cooking index`에서 확인해요.

일반 화로를 놓는 것만으로 전용 조리대가 되는 것은 아니에요. 조리대를 옮겨야 하는데 회수 권한이 없다면 관리자에게 문의해 주세요.
