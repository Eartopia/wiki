# 🌱 작물 목록

어떤 씨앗을 심을지 고를 때 참고해 주세요. 아래 시간은 뼛가루를 사용하지 않았을 때의 **기본 성장 시간**이에요.

## 기본 작물

| 작물 | 성장 시간 | 심는 재료 |
| --- | --- | --- |
| 밀 | 1시간 | 밀 씨앗 |
| 당근 | 2시간 | 당근 |
| 감자 | 2시간 | 감자 |
| 비트 | 2시간 | 비트 씨앗 |
| 네더 와트 | 4시간 | 네더 와트 |

네더 와트는 영혼 모래에, 나머지 기본 작물은 경작지에 심어요.

## 전용 작물

모두 해당 작물의 **전용 씨앗**을 경작지에 심어요. 수확량은 일반 씨앗으로 완전히 자랐을 때의 기본 범위예요.

| 작물 | 성장 시간 | 기본 수확량 |
| --- | --- | --- |
| 토마토 | 1시간 30분 | 2~4개 |
| 옥수수 | 2시간 | 1~3개 |
| 딸기 | 1시간 30분 | 3~5개 |
| 양배추 | 2시간 30분 | 1~2개 |
| 가지 | 2시간 | 1~3개 |
| 쌀 | 2시간 | 2~4개 |
| 블루베리 | 2시간 | 3~5개 |
| 라즈베리 | 2시간 | 3~5개 |
| 블랙베리 | 2시간 15분 | 3~5개 |
| 크랜베리 | 1시간 45분 | 3~5개 |
| 구스베리 | 2시간 30분 | 2~4개 |
| 레드커런트 | 2시간 10분 | 3~5개 |
| 블랙커런트 | 2시간 20분 | 3~5개 |
| 링곤베리 | 1시간 50분 | 3~5개 |
| 골든베리 | 2시간 30분 | 2~4개 |
| 키위 | 3시간 | 2~4개 |
| 파인애플 | 3시간 30분 | 1~2개 |
| 패션프루트 | 3시간 | 2~4개 |

성숙한 전용 작물에서는 기본 **씨앗 1~2개**, 미성숙 작물에서는 **씨앗 1개**가 돌아와요. 미성숙 작물에서는 수확물을 얻을 수 없어요.

풍요 씨앗과 뼛가루 사용법은 [농사 안내](../farming.md)를 확인해 주세요.
