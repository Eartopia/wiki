# 🎨 리소스팩

물고기, 농작물, 악기와 여러 메뉴는 **Eartopia 리소스팩**으로 보여요. 접속할 때 적용 안내가 나오면 수락해 주세요.

## 처음 적용하기

**멀티플레이 → Eartopia 서버 선택 → 수정 → 서버 리소스 팩: 사용**으로 설정하고 다시 접속해요.

다운로드와 적용이 끝날 때까지 기다려 주세요. 전용 아이템이 종이나 기본 아이템처럼 보인다면 아직 적용되지 않았을 수 있어요.

## 업데이트 안내가 나왔어요

안내의 적용 버튼을 누르거나 `/resourcepacks update`를 입력하면 대기 중인 업데이트를 받아요. 짧게 `/packs update`를 입력해도 돼요.

업데이트할 항목이 없다는 메시지가 나오면 추가로 받을 팩이 없는 상태예요. 이 명령어는 적용 상태를 검사하거나 모든 팩을 강제로 다시 받는 기능은 아니에요.

## 계속 이상하게 보이나요?

1. 서버 리소스 팩이 **사용**으로 설정되어 있는지 확인해요.
2. 서버에 다시 접속하고 다운로드가 끝날 때까지 기다려요.
3. 개인적으로 적용한 UI·글꼴 리소스팩을 잠시 끄고 확인해요.
4. 같은 문제가 이어지면 안내 메시지를 캡처해서 문의해 주세요.

메뉴는 보이는데 클릭 위치만 어긋나면 [패널 커서 보정](../support/panel-cursor-calibration.md)을 진행해 보세요.
