# ⚙️ 편의 설정

**`Shift+F` → 설정**에서 바꿀 수 있어요.

## 배경음악

배경음악 버튼으로 Eartopia의 배경음악을 켜거나 끌 수 있어요. 음악을 껐더라도 게임의 다른 소리까지 모두 꺼지는 것은 아니에요.

악기나 효과음이 들리지 않는다면 마인크래프트의 **설정 → 음악 및 소리**도 함께 확인해 주세요.

## 저사양 모드

저사양 모드를 켜면 HUD를 표시하는 방식이 바뀌어요. 설정은 바로 적용되고 다시 접속해도 유지돼요.

{% hint style="info" %}
저사양 모드에서는 움직일 때 HUD가 깜빡일 수 있어요. 화면이 더 불편해지면 같은 버튼으로 꺼주세요. 컴퓨터나 모드 구성에 따라 체감은 달라요.
{% endhint %}

## 언어와 클릭 위치

설정의 언어 버튼으로 표시 언어를 고를 수 있어요. 자세한 방법은 [언어 설정](language.md)을 참고해 주세요.

GUI 비율이나 화면 크기를 바꾼 뒤 클릭이 어긋나면 [커서 보정](../support/panel-cursor-calibration.md)을 다시 진행해 보세요.
