# 🚪 접속 방법

**마인크래프트 Java Edition**으로 접속해 주세요. 이 안내서는 **1.21.11** 환경을 기준으로 설명해요.

## 서버 추가하기

1. [공식 디스코드](https://discord.gg/tymyqkCJW7)에서 현재 접속 안내와 서버 주소를 확인해요.
2. 마인크래프트를 실행하고 **멀티플레이 → 서버 추가**를 눌러요.
3. 서버 이름에는 `Eartopia`, 서버 주소에는 안내받은 주소를 입력해요.
4. **서버 리소스 팩**을 **사용**으로 바꾸고 저장해요.
5. 추가한 서버에 접속하고 리소스팩이 적용될 때까지 기다려요.

{% hint style="info" %}
홈페이지 주소와 게임 접속 주소는 서로 다를 수 있어요. 서버 추가 화면에는 디스코드의 접속 안내에 적힌 주소를 입력해 주세요.
{% endhint %}

## 접속이 되지 않아요

**허용 목록에 없다는 안내**가 나오면 디스코드에서 참여 절차를 확인해 주세요. 리소스팩이나 언어 설정을 바꿔 해결하는 문제는 아니에요.

**버전이 다르다는 안내**가 나오면 실행한 버전과 최신 접속 공지를 확인해 주세요. 베드락 에디션이나 다른 버전의 접속 지원 여부도 공지를 먼저 확인해 주세요.

접속했다면 [뉴비 필독](../info/new-player.md)으로 넘어가면 돼요!
