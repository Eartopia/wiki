# 🌐 언어 설정

Eartopia의 메뉴와 안내는 **마인크래프트에서 사용하는 언어**를 따라가요. 게임 언어와 다르게 쓰고 싶다면 직접 고를 수도 있어요.

## 한국어로 설정하기

`/language set ko_KR`을 입력하면 한국어로 고정돼요. `/language`로 언어 선택 화면을 열어도 돼요.

언어를 바꿨는데 열어둔 메뉴가 그대로라면 닫았다가 다시 열어 주세요.

## 지원 언어

| 언어 | 설정 명령어 |
| --- | --- |
| 한국어 | `/language set ko_KR` |
| English | `/language set en_US` |
| 日本語 | `/language set ja_JP` |
| 简体中文 | `/language set zh_CN` |
| 繁體中文（台灣） | `/language set zh_TW` |
| Tiếng Việt | `/language set vi_VN` |

## 자동 설정으로 돌아가기

`/language auto`를 입력하면 직접 고른 언어를 해제하고 게임 언어를 따라가요. 지원하지 않는 언어는 영어로 표시돼요.

지금 적용된 언어는 `/language current`, 선택 가능한 목록은 `/language list`로 확인할 수 있어요. `/lang`도 같은 명령어예요.
