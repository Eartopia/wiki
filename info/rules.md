# 📌 이용 안내

접속 안내와 운영 공지는 [공식 디스코드](https://discord.gg/tymyqkCJW7)에서 확인해 주세요. 접속 가능 여부, 점검 일정과 이용 수칙은 최신 공지를 기준으로 확인하면 돼요.

## 함께 생활할 때

마을에 가입하기 전에는 **건축 규칙과 세금**을 먼저 물어보세요. 같은 마을이어도 개인 땅과 공동 창고의 사용 범위는 다를 수 있어요.

다른 사람의 물건이나 건축물을 사용할 때는 주인의 동의를 구해 주세요. 게임에서 상자가 열린다고 해서 공동 창고라는 뜻은 아니에요.

## 문제가 생겼나요?

오류를 제보할 때는 아래 내용을 함께 알려주시면 확인에 도움이 돼요.

- 문제가 생긴 시각과 사용한 메뉴 또는 명령어
- 어떤 순서로 조작했는지
- 화면에 나온 안내 문구와 스크린샷
- 아이템이 관련되어 있다면 이름과 수량

홈페이지 로그인 인증코드는 본인 확인에 쓰이니 다른 사람에게 보내지 마세요. 문의 화면에도 코드가 보이지 않게 해주세요.
