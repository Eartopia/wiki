# 👋 주민 생활과 초대

마을에 들어왔다면 먼저 집을 지을 자리와 공동 시설을 안내받아 보세요.

## 주민 초대하기

마을장이나 초대 권한이 있는 주민은 `/town add <닉네임>`으로 초대할 수 있어요. 초대받은 사람은 `/invite accept <마을이름>`으로 수락하면 돼요.

메인 메뉴의 마을 관리 화면과 초대 화면에서도 진행할 수 있어요.

## 내 마을 확인하기

| 명령어 | 하는 일 |
| --- | --- |
| `/town` | 내 마을의 정보를 봐요. |
| `/town reslist` | 마을 주민을 확인해요. |
| `/town spawn` | 내 마을 스폰으로 돌아가요. |
| `/resident` | 내 주민 정보를 봐요. |

## 탈퇴하거나 주민을 내보낼 때

`/town leave`로 마을을 떠날 수 있어요. 마을 관리자는 `/town kick <닉네임>`으로 주민을 내보낼 수 있어요.

탈퇴 전에는 **개인 땅, 보관한 아이템과 이용 중인 시설**을 정리해 주세요. 탈퇴한 뒤에는 같은 장소에 돌아오더라도 이전 권한으로 사용할 수 없을 수 있어요.

마을 운영을 넘기거나 해산하려는 경우에는 마을 관리 화면의 안내를 확인해 주세요. 단순히 탈퇴하는 일과는 달라요.
