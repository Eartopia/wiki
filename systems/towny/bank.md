# 🪙 금고와 세금

**내 돈과 마을 금고는 따로 관리돼요.** 내 잔액이 충분해도 마을 금고가 비어 있으면 운영에 문제가 생길 수 있어요.

## 금고 채우기

`/town deposit <금액>`으로 마을 금고에 입금해요. 출금 권한이 있는 사람은 `/town withdraw <금액>`을 사용할 수 있어요.

마을 정보와 메뉴에서 잔액을 확인하고, 땅을 넓히기 전에는 확장 비용도 마련해 주세요.

## 어떤 비용이 있나요?

2026년 9월 22일 기준 기본 설정이에요. 마을·국가 상태나 창립 지원에 따라 실제 청구액은 달라질 수 있어요.

| 항목 | 기본 금액 |
| --- | ---: |
| 마을 생성 | $250 |
| 국가 생성 | $1,000 |
| 마을 영토 1청크 확보 | $25 |
| 마을 하루 유지비 | $10 |
| 국가 하루 유지비 | $100 |

**유지비와 주민 세금은 달라요.** 유지비는 마을·국가 운영에 드는 비용이고, 주민 세금이나 플롯 세금은 소속 마을의 설정에 따라 달라져요.

## 가입 전에 확인해 주세요

마을에 들어가기 전에 주민 세금, 집터 가격과 개인 땅의 세금을 물어보세요. 접속하지 않는 동안에도 운영비와 세금에 대비할 여유를 두는 게 좋아요.

교역을 꾸준히 진행했다면 [창립 지원](../trade/founding.md)으로 비용을 줄일 수 있는지도 확인해 보세요.
