# 🏠 마을 만들기

원하는 지구의 지역에 도착했다면 **주변 마을과 땅의 상태**부터 확인해 주세요.

## 자리 고르기

`/towny map`으로 주변 마을을 확인하고, `F3+G`로 청크 경계를 켜보세요. 마을을 만드는 위치의 청크가 첫 영토가 돼요.

다른 마을과 너무 가까우면 만들 수 없어요. 나중에 밭과 길을 놓을 자리까지 생각해서 골라보세요.

## 마을 생성하기

원하는 자리에 서서 `/town new <마을이름>`을 입력해요. 예를 들어 `/town new 별숲`처럼 쓸 수 있어요.

마을 생성에는 비용과 생성 조건이 있어요. [금고와 세금](bank.md)을 확인하고, 교역을 진행했다면 [개척자 창립 지원](../trade/founding.md)도 살펴보세요.

생성이 끝나면 `/town`으로 내 마을 정보를 확인해요. 마을 메뉴에서는 스폰 설정, 주민 초대와 영토 관리로 이어갈 수 있어요.

## 마을 스폰 정하기

마을 땅 안에서 주민이 도착할 안전한 자리에 서서 `/town set spawn`을 입력해요. 설정한 뒤 `/town spawn`으로 확인해 보세요.

## 처음부터 챙길 것

1. 주민이 도착할 안전한 스폰을 정해요.
2. `/town deposit <금액>`으로 마을 금고에 운영비를 넣어요.
3. 필요한 만큼만 [영토를 넓혀요](land.md).
4. 함께 살 사람을 [초대해요](residents.md).

마을을 지우는 기능은 되돌리기 어려워요. 이름이나 스폰만 바꾸려는 경우에는 해당 설정을 먼저 확인해 주세요.
