# 🤝 물물교환

Eartopia 교역소에서는 **특산물끼리** 교환할 수 있어요. `/trade market`으로 주문판을 열어보세요.

## 등록된 주문 이용하기

내가 받을 물품과 내놓을 물품의 **종류·수량·신선도**를 확인해요. 조건에 맞는 물품을 준비한 뒤 주문판에서 교환을 진행하면 돼요.

교환이 끝난 물품은 바로 손에 들어오는 대신 **배송 보관함**에 들어가요. `/trade deliveries`로 받아 주세요.

## 내 주문 등록하기

1. 맡길 정식 특산물을 손에 들어요.
2. 도감에서 받고 싶은 특산물의 번호를 확인해요.
3. `/trade market create <받을물품번호> <받을수량> <맡길수량>`을 입력해요.
4. 등록 완료 안내를 확인하고 `/trade market mine`에서 내 주문을 살펴봐요.

예를 들어 올리브를 손에 들고 `/trade market create 33 2 4`를 입력하면, **올리브 4개를 맡기고 팥 2개를 받는 주문**을 등록해요. 이 수량은 사용법을 보여주는 예시예요.

{% hint style="warning" %}
등록 명령어는 조건을 충족하면 바로 물품을 맡기고 주문을 만들어요. 입력 전에 받고 싶은 물품 번호와 양쪽 수량을 확인해 주세요.
{% endhint %}

## 주문 제한과 취소

- 내 활성 주문은 최대 **3개**예요.
- 새 주문을 연속으로 만들 때는 **10초** 간격이 필요해요.
- 주문은 최대 **24시간** 유지돼요. 신선도가 먼저 부족해지면 더 일찍 만료돼요.
- 교환할 때 양쪽 물품의 신선도가 **10분 이상** 남아 있어야 해요.

`/trade market mine`에서 내 주문을 확인하고 취소할 수 있어요. 취소되거나 만료된 물품도 `/trade deliveries`로 돌려받아요.

{% hint style="info" %}
주문에 맡긴 물품은 교환을 기다리는 동안 사용할 수 없어요. 같은 물품을 계약에도 쓸 예정이라면 수량을 나눠 준비해 주세요.
{% endhint %}
