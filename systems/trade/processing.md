# 🫙 가공과 신선도

`/trade processing`을 열면 가공할 수 있는 특산물을 볼 수 있어요. 레시피의 **지역, 재료, 단계와 남은 신선도**를 함께 확인해 주세요.

## 가공하기

1. 가공 메뉴에서 만들 물품을 골라요.
2. 필요한 재료를 인벤토리에 준비해요.
3. 가공을 시작하고 완료 시간을 기다려요.
4. `/trade deliveries`로 결과를 받아요.

인벤토리가 가득 찼다면 자리를 비우고 다시 수령해 주세요.

## 예시: 올리브유 만들기

기본 레시피에서는 **올리브 3개**로 **엑스트라 버진 올리브유**를 만들어요. 가공 시간은 기본 **3분**이고, 유럽 지역 조건이 적용돼요.

도감에서 올리브유의 번호를 확인했다면 `/trade processing 18`로 시작할 수도 있어요. 처음에는 메뉴에서 재료와 조건을 읽으며 진행하는 편이 쉬워요.

연구가 진행되면 가공 시간이 줄거나 가공 가능한 단계와 슬롯이 늘어날 수 있어요.

## 신선도는 이어져요

가공품의 신선도는 투입한 재료의 상태를 이어받아요. 오래된 재료를 가공하거나 다른 사람에게 넘겨도 남은 시간이 새로 채워지지는 않아요.

가공이 끝나기 전에 신선도가 다하면 시작할 수 없어요. 여러 재료를 섞을 때는 신선도가 얼마 남지 않은 재료부터 확인해 주세요.

## 가공 결과가 안 보여요

먼저 `/trade deliveries`를 확인해 보세요. 완료 안내를 받았는데도 결과를 받을 수 없다면 메뉴의 안내 문구를 남겨 문의해 주세요.

[오늘의 계약](contracts-research.md)에서 필요한 물품을 먼저 확인하면 불필요한 가공을 줄일 수 있어요.
