# 📋 계약과 연구

`/trade contracts`에서 **오늘의 계약 3개**를 확인할 수 있어요. 계약은 **한국 시간 날짜**를 기준으로 바뀌어요.

## 세 종류의 계약

| 종류 | 살펴볼 내용 |
| --- | --- |
| 내수 | 내 생활 권역에서 마련할 물품 |
| 수입 | 다른 지역의 물품을 구해야 하는 목표 |
| 교류 | 가공이나 다른 사람과의 교환을 활용할 목표 |

실제 품목과 수량은 당일 계약 화면을 기준으로 준비해 주세요. 신선한 정식 특산물을 인벤토리에 넣고, 해당 계약의 납품 안내를 따라가면 돼요.

## 혼자 할 때와 국가에서 할 때

**개척자 계약**은 개인의 교역 성장과 연결돼요. **국가 계약**은 국가 소속으로 진행하고 국가 연구에 필요한 자원을 모으는 데 도움이 돼요.

생활 권역이나 소속을 바꿔 같은 날의 계약을 다시 받는 방식은 사용할 수 없어요. 오늘 적용되는 범위를 계약 화면에서 확인해 주세요.

## 연구하기

`/trade research`를 열면 연구 조건과 필요한 자원을 볼 수 있어요.

| 연구 | 이어지는 성장 |
| --- | --- |
| 생산 | 하루 생산 여유, 상위 가공과 가공 슬롯 |
| 물류 | 가공 시간 단축 |
| 협력 | 교류 계약 보상과 창립 지원 자격 |

연구는 단계별 선행 조건이 있어요. 국가 연구는 **국왕이 승인**하므로, 어떤 연구부터 진행할지 함께 정해 보세요.

혼자 교역을 시작했다면 계약을 마치며 평판을 쌓고 **협력 I**을 목표로 삼아보세요. [개척자 창립 지원](founding.md)으로 이어갈 수 있어요.
